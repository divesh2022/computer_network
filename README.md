Welcome to the official practical repository for **CSPC-511P: Computer Networks Lab**. This lab is designed to provide hands-on experience with networking hardware, protocols, and configurations. It complements theoretical learning with practical exposure to real-world networking scenarios.

## 🧪 Lab Objectives

- Understand and configure basic networking components and protocols.
- Gain hands-on experience with LAN setup, IP addressing, and subnetting.
- Learn to design and implement small-scale networks using both IPv4 and IPv6.
- Develop troubleshooting and configuration skills in both Windows and Linux environments.

---

## 🧰 Required Infrastructure

- LAN adapters, switches, hubs, routers
- Co-axial and UTP cables, crimping tools, RJ-45 connectors
- Computers with Windows and Linux OS
- Access to network configuration tools (e.g., Wireshark, Packet Tracer)

---

## 🧭 Experiment List

> A minimum of **8 experiments** must be performed. Additional experiments may be conducted based on institutional resources.

### 1. Networking Components Familiarization
- Identify and understand the function of LAN cards, hubs, switches, routers.
- Document specifications and use cases.

### 2. Transmission Media & Tools
- Explore co-axial and UTP cables.
- Practice using crimping tools and connectors.

### 3. Cable Preparation
- Create straight-through and cross-over Ethernet cables.
- Test connectivity using cable testers.

### 4. LAN Topology Implementation
- Set up star, bus, and ring topologies using physical devices.
- Analyze performance and fault tolerance.

### 5. TCP/IP Configuration
- Configure static and dynamic IPs in Windows and Linux.
- Verify connectivity using `ping`, `ipconfig/ifconfig`, and `traceroute`.

### 6. File & Printer Sharing
- Share directories and printers across a LAN.
- Set permissions and test access from client machines.

### 7. IP Addressing (Class A, B, C)
- Design and assign IP addresses for different classes.
- Validate network communication.

### 8. Subnetting & Implementation
- Perform subnet calculations.
- Apply subnetting in a simulated or real network.

### 9. IPv6 Address Planning
- Design an IPv6 scheme for a LAN with *n* terminals.
- Configure and test IPv6 connectivity.

### 10. Switch & Router Configuration
- Access device CLI (e.g., Cisco IOS).
- Configure basic routing and VLANs.
